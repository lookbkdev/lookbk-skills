# Notices

Services Menu Kit is a Lookbk skill. The section design, the stylesheet, the
browser runtime, the build, schema, check, server and recorder, the two
examples (Marrow Street Studio and Keelson Data, which are invented: their
names, copy, services, prices, durations and figures are not real) and this
documentation were written for Lookbk.

Every mark, rule, leader and bill on the page is drawn in HTML and CSS by the
kit. No images, video or icons are shipped.

Included here:

- `scripts/kit/cdp.mjs`, `scripts/kit/serve.mjs` and `scripts/chrome.mjs`
  are Lookbk's shared helpers from the Motion Heroes, Scroll Cinema and FAQ
  Kit packages.

No third-party code is vendored or loaded: the runtime is Lookbk's own.

Fetched when a built page is opened, not shipped here, each from Google
Fonts under the SIL Open Font License 1.1 and copyright its authors:

- **Libre Caslon Display**, **Libre Caslon Text** and **Libre Franklin**
  (the `caslon` type system)
- **Archivo**, **IBM Plex Sans** and **IBM Plex Mono** (the `archivo` type
  system)

Used on your machine, not shipped: Chrome, Chromium or Edge (driven over the
DevTools protocol) and ffmpeg.
