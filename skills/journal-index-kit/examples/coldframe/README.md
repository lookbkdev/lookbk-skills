# Coldframe Journal (example)

An invented furniture and interiors studio's journal: 11 pieces in five
sections, two series, the `paper` preset with Newsreader and Schibsted
Grotesk, drop caps, photographs as lead images.

Build it with `node scripts/build.mjs examples/coldframe out/coldframe`.

The example photographs were generated for this demo; replace them with your
own. Every name, project and number in the posts is invented.
