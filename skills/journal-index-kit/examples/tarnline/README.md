# Tarnline Engineering (example)

An invented database company's engineering blog: 10 pieces in five sections,
two series, the `ink` preset with Geist, Source Serif 4 and Geist Mono,
charts drawn from `charts/*.json` as lead figures, code with marked lines,
and `indexLimit: 8`, so the build also writes `archive/`.

Build it with `node scripts/build.mjs examples/tarnline out/tarnline`.

Every name, incident, number and chart in the posts is invented.
