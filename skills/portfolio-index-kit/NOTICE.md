# Notices

Work Index is a Lookbk skill. The two row systems, the plate and its
placement rule, the stylesheet, the browser runtime, the build, checks,
server and recorder, the two examples (Fenn Type Office and Teodor Halm,
which are invented: their names, clients, projects, credits, places,
numbers and addresses are not real) and this documentation were written for
Lookbk.

Every picture in the examples, and the one loop, was drawn in code for
Lookbk (SVG rendered in headless Chrome by `examples/art/draw.mjs`): type
specimens, posters, a record sleeve, a station sign, book covers, a
catalogue spread and nine buildings in light. No photographs, stock images
or generated images are used or shipped.

Included here:

- `scripts/kit/cdp.mjs`, `scripts/kit/serve.mjs` and `scripts/chrome.mjs`
  are Lookbk's shared helpers from the Motion Heroes, Scroll Cinema and
  Closing CTA packages.

No third-party code is vendored or loaded: the runtime is Lookbk's own.

Fetched when a built page is opened, not shipped here, each from Google
Fonts under the SIL Open Font License 1.1 and copyright its authors:

- **Bricolage Grotesque** and **DM Mono** (the `bricolage` display)
- **Instrument Serif**, **Geist** and **Geist Mono** (the `instrument`
  display)

Used on your machine, not shipped: Chrome, Chromium or Edge (driven over the
DevTools protocol) and ffmpeg.
